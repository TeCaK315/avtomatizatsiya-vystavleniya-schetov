# AutoInvoice Pro

## Описание
AutoInvoice Pro - это инструмент для автоматизации выставления счетов, который помогает малым и средним предприятиям минимизировать ошибки и ускорять обработку.

## Установка
1. Клонируйте репозиторий
2. Установите зависимости
3. Запустите приложение

## Использование
- Загрузите PDF-файл счета
- Автоматически извлеките данные
- Отправьте счет клиенту
